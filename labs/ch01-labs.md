## 实验 1.1 安装、扫码登录与功能自检

- **实验目的**：独立完成 WorkBuddy 桌面端的下载安装（下载安装包 → 运行安装包 → 完成安装指引）、微信扫码登录与版本、连通性自检，建立“环境可用”基线。
- **前置条件**：Windows 10 及以上（不支持 Windows 7/8/8.1）或 macOS 12 (Monterey) 及以上的电脑（不满足上述要求的系统将无法启动 WorkBuddy）；可联网（需要网络连接以调用 AI 模型服务）；需注册并登录 WorkBuddy 账号。
- **操作步骤**：
  1. 第一步：下载安装包。访问 WorkBuddy 官网（https://www.codebuddy.cn/work/），鼠标悬停“下载 WorkBuddy”（Windows 页面为点击“立即下载”），选择适配当前设备的版本后点击下载：
     - Windows：点击“立即下载”，等待安装包下载完成；
     - macOS：M 系列芯片选择 Mac ARM64 版本，Intel 芯片选择 Mac X64 版本；如不确定芯片类型，可点击屏幕左上角的苹果图标 →“关于本机”查看；在浏览器弹窗中允许下载，等待安装包下载完成。
  2. 第二步：运行安装包。在浏览器下载完成后，双击运行安装包：
     - Windows：双击已下载的安装包，启动安装程序；
     - macOS：双击已下载的 .dmg 磁盘映像文件，打开安装窗口；将 WorkBuddy 图标拖入 Applications 文件夹，等待拷贝完成；随后推出已挂载的 WorkBuddy 磁盘映像（如不再需要，可删除下载目录中的 .dmg 安装包）。
  3. 第三步：完成安装指引。跟着安装指引完成安装：
     - Windows：勾选“我同意此协议”，点击“下一步”；选择安装位置（默认路径可直接点击下一步），点击“下一步”；确认开始菜单文件夹，点击“下一步”；建议勾选“创建桌面快捷方式”，点击“下一步”；确认配置无误，点击“安装”；安装完成后，点击“完成”退出安装向导；
     - macOS：拖拽方式安装，将图标拖入 Applications 文件夹后即安装成功，无需额外指引。
  4. 微信扫码登录：
     - 启动 WorkBuddy（macOS 可通过“启动台”或 Command + 空格 搜索打开）；
     - 点击“登录”按钮，跳转到浏览器（macOS 浏览器将自动打开登录页面）完成微信扫码登录；
     - 登录前勾选《服务条款》与《隐私协议》（首次登录时勾选同意用户服务协议）；
     - 个人用户选择“个人”登录方式，购买企业版的用户选择“企业”登录方式；
     - 登录成功后自动返回客户端，即可开始使用。
  5. 版本检查：点击左下角“头像 → 检查更新”（macOS 为“个人中心 → 检查更新”），系统将自动检测版本：若已是最新版本则无需操作；若存在新版本，系统将自动下载并完成升级。如需切换界面语言，可点击左下角“头像 → 语言”进行切换（macOS 对应入口以产品实际界面为准）。
  6. 连通性自检：在底部输入框描述一条测试任务（如：

     ```text
     你好，请介绍一下你自己
     ```

     ），点击“发送”，观察 WorkBuddy 是否正常回复。
- **预期结果与验收标准**：
  - 安装过程无报错，应用可正常启动；
  - 微信扫码后登录成功，个人/企业登录方式选择正确，客户端头像/账号状态为已登录；
  - “检查更新”显示已是最新版本，或自动完成升级；
  - 测试消息得到正常回复，说明网络与账号配置成功。
- **官方文档出处**：（[官方文档《快速开始》](https://www.workbuddy.cn/docs/workbuddy/Quickstart)）（[官方文档《开启你的第一个任务》](https://www.workbuddy.cn/docs/workbuddy/FirstTask)）（[官方文档《Windows 安装指南》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide)）（[官方文档《macOS 安装指南》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide)）

## 实验 1.2 主界面三区域与新建任务栏

- **实验目的**：识别主界面三大区域（侧边栏、对话区、结果区）与新建任务栏的关键配置入口，并完成一次“新建任务 → 描述任务 → 发送执行 → 查看结果”的完整操作。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. 观察主界面三大区域，对照官方《快速开始》确认各自作用：
     - 侧边栏：显示任务列表（按文件夹分组），支持搜索和管理，底部显示用户头像；
     - 对话区：核心交互区域，包含任务标题栏、消息列表和输入框；
     - 结果区：右侧面板，展示“概览（工作空间文件、浏览器、变更、产物）”等视图；任务产生对话后，从右上角展开该面板，即可在同一界面完成阅读、编辑与核对。
  2. 新建任务：在主界面点击“新建任务”开始创建 PC 端的任务；每个对话对应一个“独立任务”，任务之间互不影响，各自维护独立的工作空间与上下文（若未提前指定目录，系统会自动创建独立工作目录）。执行中的任务显示在左侧边栏，可随时切换查看进度，WorkBuddy 支持多任务并行处理。注意：在移动端发送的任务是在“助理”中查看（WorkBuddy 支持连接 WorkBuddy 小程序、WorkBuddy App，接入微信助理、微信客服号、企微助理、QQ 机器人、飞书、钉钉机器人等移动端集成）。
  3. 在底部新建任务栏逐个找到以下配置入口并确认用途：
     - 工作模式切换：问一问（Ask）/ 做一做（Craft）/ 想一想（Plan）三种工作模式；
     - 切换模型：MiniMax、智谱 GLM、Kimi、DeepSeek、腾讯混元等内置模型，可按需灵活切换；
     - 设置工作空间：使用前建议先设置工作空间，WorkBuddy 将在该空间中读取和保存文件，未指定路径的任务也会优先在此空间内执行；设置时直接在文件选择器中定位并选中目标文件夹即可（无需手动输入路径）；若未提前指定，WorkBuddy 会在新建任务时自动创建独立空间；
     - 选择技能：技能（Skills）用于扩展任务能力，在对话框中选择已安装技能，执行任务时将自动调用对应能力（如 PPT 制作、海报生成、自动化报表等）；
     - 连接第三方应用：快捷管理连接器，连接外部服务，扩展 AI 能力；
     - 权限管理：在新建任务输入框下方点击“默认权限”下拉菜单，可在“默认权限”与“完全访问权限”之间切换。
  4. 描述任务并执行：在对话框中描述你的任务要求（如：

     ```text
     写一份 200 字的请假条
     ```

     ），点击“发送”，WorkBuddy 开始执行任务。
  5. 查看结果：打开右侧窗口查看任务结果：生成的目标文件在“产物”中可以找到；任务产生的其他文件可在“概览-工作空间文件”中查看（以树状结构浏览当前工作目录）；“变更”记录 WorkBuddy 对文件的所有修改，展开可查看具体变更文件并通过差异对比确认改动。
  6. 在左侧侧边栏查看任务列表，确认按文件夹分组展示、支持搜索与管理（具体分组方式以产品实际界面为准）。
  7. 尝试把一份本地文件拖入输入框，确认可通过拖拽/上传挂载素材（以产品实际界面为准）。
- **预期结果与验收标准**：
  - 能准确说出三区域各自的作用（侧边栏：任务列表按文件夹分组、可搜索管理、底部头像；对话区：任务标题栏、消息列表、输入框；结果区：概览——工作空间文件、浏览器、变更、产物）；
  - 能在任务栏中找到至少 6 个配置入口（工作模式、模型、工作空间、技能、连接器、权限）并能说明用途；
  - 新建任务执行后，在右侧结果区“产物”中找到生成文件，在“概览-工作空间文件”中浏览其他文件；
  - 拖拽文件后输入框出现文件挂载提示（以产品实际界面为准）。
- **官方文档出处**：（[官方文档《快速开始》](https://www.workbuddy.cn/docs/workbuddy/Quickstart)）（[官方文档《新建任务栏》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)）（[官方文档《右侧边栏》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Right-Sidebar)）（[官方文档《开启你的第一个任务》](https://www.workbuddy.cn/docs/workbuddy/FirstTask)）（[官方文档《任务管理》](https://www.workbuddy.cn/docs/workbuddy/Task-Management)）（[官方文档《创建任务》](https://www.workbuddy.cn/docs/workbuddy/Create-Task)）

## 实验 1.3 Ask / Plan / Craft 三模式对比

- **实验目的**：用同一类任务分别在问一问（Ask）、想一想（Plan）、做一做（Craft）三种工作模式下执行，验证三种模式的行为差异。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. 在新建任务栏切换工作模式为“问一问（Ask）”，发送任务：

     ```text
     把这段文字改写成更正式的语气，原文：……
     ```

     ；执行后确认本地文件未被修改（Ask 仅问答与信息查看，不修改文件，适用于了解内容、确认需求）。
  2. 切换为“想一想（Plan）”，发送任务：

     ```text
     分析 D:/实验目录/销售数据.xlsx，提取月度趋势并生成一份汇报 PPT 大纲
     ```

     ；观察是否先生成执行计划、确认后再操作（Plan 先生成执行计划，确认后再操作，适合多步骤任务、需审阅改动范围）。建议保持输入框下方的权限为“默认权限”，未授权前不落盘。
  3. 切换为“做一做（Craft）”，发送一个明确的文档生成任务（如：

     ```text
     写一份 200 字的请假条
     ```

     ），观察是否直接执行任务并产出文件（Craft 直接执行任务并修改文件，适用于文档生成、表格处理、文件整理）。
  4. 按官方建议验证模式选择原则：首次使用优先选择 Ask 模式；熟悉后再按任务复杂度切换至 Plan 或 Craft 模式；处理重要文件前请先备份。
- **预期结果与验收标准**：
  - Ask：只返回文字回复，本地文件零变更；
  - Plan：先出现计划确认环节，未授权前不落盘；
  - Craft：跳过计划确认，直接执行并产出文件；
  - 三者行为差异与《新建任务栏》文档的模式说明一致（问一问：仅问答与信息查看、不修改文件；想一想：先生成执行计划、确认后再操作；做一做：直接执行任务并修改文件）。
- **官方文档出处**：（[官方文档《新建任务栏》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)）

## 实验 1.4 系统设置与记忆管理（可选）

- **实验目的**：验证系统设置（语言、字体、简洁模式、非高风险自动安装、防休眠）与记忆管理的常见选项。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. 进入系统设置：点击左下角“头像 → 设置 → 系统设置”，依次尝试修改以下个性化选项，确认即时生效：
     - 语言：支持切换“中文（简体）”和 English；
     - 字体大小；
     - 显示模式：开启“简洁模式”后，对话界面显示被简化，隐藏部分装饰性元素，并折叠对话中工具调用等过程信息（官方默认开启简洁模式）。
  2. 找到“非高风险自动安装”选项，理解其作用：上传 Skill 后仍会显示安全检测过程；非高风险自动继续安装；高风险始终需要手动确认。
  3. 找到“防休眠”选项，理解其作用：开启后你的电脑系统将不会进入休眠，方便手机远程操控、自动化任务持续进行。
  4. 打开记忆管理：从头像处进入“设置 → 记忆”，依次检查：
     - “生成对话记忆”开关：默认开启，允许 WorkBuddy 从对话中提取并记住相关上下文，以便在未来对话中提供更连贯、个性化的回应；
     - 管理记忆：查看（记忆摘要每晚重新生成，打开已生成的记忆可查看记忆内容）、编辑（点击右上角编辑图标，通过对话的方式告诉 WorkBuddy 要记住或忘记什么）、删除（点击右上角删除图标，清空当前记忆）；
     - 导入记忆：点击“开始导入”，复制示例提示词到其他 AI 产品的对话中，将结果粘贴到下方，点击“添加到记忆”完成导入（记忆内容仅您本人可见，不涉及积分消耗）。
  5. 可选：关闭“生成对话记忆”后再重新开启，观察记忆开关的即时生效（关闭后将停止提取新的记忆）。
- **预期结果与验收标准**：
  - 设置项修改后界面即时刷新；
  - 能说明“非高风险自动安装”（非高风险自动继续安装、高风险始终需要手动确认）与“防休眠”（防止电脑休眠，便于手机远程操控与自动化任务持续进行）等选项的作用；
  - 记忆管理页面可见“生成对话记忆”开关（默认开启）、记忆生成状态（每晚整理当天会话）与“开始导入”入口。
- **官方文档出处**：（[官方文档《系统设置》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Setting)）（[官方文档《记忆》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Memory)）（[官方文档《默认权限与安全沙箱》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Permission-Modes)）
