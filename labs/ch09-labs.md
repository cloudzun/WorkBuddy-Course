# 第 9 章 典型办公场景综合实战与 OPC 一人公司 · 综合演练

> 本章为**贯穿式综合演练**：以“我的咖啡品牌·季度经营分析”为主线，单人完成“任务拆解 → 数据分析 → 报告生成 → PPT → 深度研究 → 轻量发布 → 自动化 → OPC 复盘”全链路，最终输出一份可对外交付的作品集。每个阶段以官方实践案例为操作蓝本，阶段产物流入下一阶段。
> 图例：**★ 必做阶段**（仅需 WorkBuddy 基础环境）；**○ 可选扩展**（需对应授权/配置）。
> 建议用时：4-6 小时（可分 2 次完成）；允许复用前八章任一实验的产物。

## 演练前准备

- **样例数据**：自建一份“季度销售数据”文件（CSV/XLSX，建议 8-12 行），字段至少包含：月份、产品线（如 经典意式/风味拿铁/冷萃/茶饮）、销售额、利润、渠道（堂食/外卖/电商）。数据可自拟，保证存在 1-2 处明显波动（如某月某产品线大幅下降），供后续分析发现。
- **环境**：完成第 1 章实验 1.1；把样例数据放入演练专用的工作空间。

## 阶段 0 项目设定与任务拆解

- **实验目的**：用自驱四要素（说清目标 / 指定输出 / 限定边界 / 自检后交付，官方实践九）定义项目目标，并把大任务拆解为可执行子任务清单。
- **前置条件**：完成演练前准备。
- **操作步骤**：
  1. 写清项目目标（示例）：

     ```text
     用 WorkBuddy 完成「我的咖啡品牌」Q2 经营分析：输出数据图表、经营分析报告、汇报 PPT 与网页版简报，并配置每周自动推送经营简报。
     ```

  2. 按自驱四要素把目标写成总任务描述：说清目标（分析 Q2 经营并交付四类产物）、指定输出（图表/报告/PPT/网页链接/自动化任务）、限定边界（仅用演练数据，不引入外部敏感数据）、自检后交付（每阶段产物自检后再进入下一阶段）。
  3. 把总任务拆解为子任务清单，映射到阶段 1-6（数据→报告→PPT→深度研究→发布→自动化）。
  4. 自检：目标是否可衡量、输出格式是否明确、边界是否清晰。
- **预期结果与验收标准**：
  - 任务描述包含自驱四要素，目标可衡量；
  - 子任务清单覆盖 数据→报告→PPT→发布→自动化 全链路；
  - 能说出每阶段对应前几章的能力（如数据分析=第 5/9 章、自动化=第 8 章）。
- **官方文档出处**：（[官方文档《实践九：AI 自驱动》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Nine)）（[官方文档《创建任务》](https://www.workbuddy.cn/docs/workbuddy/Create-Task)）

## 阶段 1 取数与数据分析

- **实验目的**：验证“导入数据 → 描述分析需求 → 生成图表与结论”的数据分析全流程（官方实践三）。
- **前置条件**：完成阶段 0；样例数据已放入工作空间。
- **操作步骤**：
  1. 把“季度销售数据”文件拖入对话（或通过资料库连接腾讯文档/ima 取数，○ 可选）。
  2. 一次说清分析需求：需要分析的指标（销售额、利润）、想看的图表类型（柱状图、折线图）、统计维度（按月份、产品线、渠道）、是否需要输出报告（官方实践三建议）。
  3. 下达任务，可采用官方实践三示例指令：

     ```text
     请读取这份销售数据，按月份统计各产品线的销售额和利润，分别生成柱状图与折线图，并补充一段结论说明。
     ```

  4. 在结果区（概览-工作空间文件/图表）核对统计结果与图表是否与数据一致。
- **预期结果与验收标准**：
  - 图表与结论与原始数据一致（可抽查 1-2 个数值）；
  - 结论覆盖：整体表现、表现最好的产品线/渠道、明显的异常波动（对应样例数据中的下降项）；
  - 分析结果可直接作为阶段 2 报告的素材。
- **官方文档出处**：（[官方文档《实践三：数据分析并可视化》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Three)）（[官方文档《结果查看》](https://www.workbuddy.cn/docs/workbuddy/Results)）

## 阶段 2 报告生成与人机双写

- **实验目的**：基于阶段 1 结论生成正式经营分析报告，体验人机双写（MD 审阅与 AI 修订）。
- **前置条件**：完成阶段 1。
- **操作步骤**：
  1. 基于分析结论，让 WorkBuddy 生成报告初稿：包含执行摘要、经营表现、问题发现（异常波动归因）、下季度建议。
  2. 打开人机双写：人工补充判断与背景，AI 以修订建议形式提出修改，人工接受/拒绝后写入正文（官方《人机双写》口径：AI 修改以修订建议呈现，接受后才写入）。
  3. 执行“自检后交付”：检查报告信息完整性、有无敏感数据、格式是否符合要求（自驱四要素之“自检”）。
- **预期结果与验收标准**：
  - 报告结构完整（摘要/表现/问题/建议四部分）；
  - 双写修订流程可复现（至少完成 1 次 AI 修订→人工接受）；
  - 自检清单执行过，报告可交付。
- **官方文档出处**：（[官方文档《人机双写》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Knowledge-Base/Cowriting)）（[官方文档《实践九：AI 自驱动》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Nine)）

## 阶段 3 PPT 与演示

- **实验目的**：把报告转成面向管理层的汇报 PPT，完成“需求到大纲 → 生成 → 美化 → 演示辅助”全流程（官方实践二）。
- **前置条件**：完成阶段 2。
- **操作步骤**：
  1. 需求到大纲：说明受众（管理层）、场景（季度汇报）、期望页数（如 8-10 页）与视觉风格。
  2. 自动生成 PPT：AI 根据大纲与模板生成完整幻灯片。
  3. 内容迭代与美化：通过对话微调特定页面（引用阶段 2 报告的核心结论与图表）。
  4. 演示辅助：让 AI 基于 PPT 内容补充讲解要点或汇报备注（具体能力以产品实际界面为准）。
  5. ○ 可选：用设计创意模式生成封面视觉或海报。
- **预期结果与验收标准**：
  - PPT 覆盖报告核心结论（摘要/表现/问题/建议）；
  - 至少完成 1 次针对单页的对话微调；
  - 讲稿/备注可用，可直接汇报。
- **官方文档出处**：（[官方文档《实践二：文档生成与编辑》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Two)）（[官方文档《设计创意》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Design-Idea)）

## 阶段 4 深度研究与决策建议

- **实验目的**：对一个开放问题做深度调研，输出含来源的结构化决策建议（官方口径：对复杂问题进行深度调研并输出报告）。
- **前置条件**：完成阶段 2。
- **操作步骤**：
  1. 选定研究问题（示例）：

     ```text
     咖啡行业 Q2 渠道投放与新品趋势，以及对我品牌的产品线调整建议
     ```

  2. 一次性说清研究目标（官方《深度研究》建议）。
  3. 下达深度研究任务；○ 可选：召唤领域专家协助研究（如品牌营销类专家团）。
  4. 审阅输出：确认包含核心结论、数据图表、可追溯的引用来源与行动建议。
- **预期结果与验收标准**：
  - 研究输出含结论、来源引用与行动建议；
  - 建议与阶段 2 报告的“下季度建议”可衔接（相互印证或补充）；
  - 对来源无法核实的内容保持谨慎，标注“以官方/权威来源为准”。
- **官方文档出处**：（[官方文档《WorkBuddy 简介》](https://www.workbuddy.cn/docs/workbuddy/Overview)）（[官方文档《专家》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center)）

## 阶段 5 轻量发布与沉淀

- **实验目的**：把报告做成 HTML 页面并轻量发布为 workbuddy.link 在线链接，同时把产物存回资料库（官方《轻量发布》《资料库》）。
- **前置条件**：完成阶段 2（报告）与阶段 1（图表）。
- **操作步骤**：
  1. 让 WorkBuddy 把经营分析报告生成一份 HTML 简报页面（含图表与结论）。
  2. 使用轻量发布：将本地 HTML 一键上传发布为 workbuddy.link 在线链接（官方文档：发布后的链接使用 workbuddy.link 域名），任何获得链接的人均可访问。
  3. 安全自查：发布前确认页面不含敏感信息（数据已脱敏）。
  4. ○ 可选：把最终产物（报告/PPT/链接）上传存回资料库，形成沉淀。
- **预期结果与验收标准**：
  - 得到可访问的 workbuddy.link 链接，页面内容与报告一致；
  - 发布前完成数据脱敏自查；
  - 存回资料库的产物可在对应平台查看（如按团队空间储存，以产品实际为准）。
- **官方文档出处**：（[官方文档《轻量发布》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Library/Lightweight-Publish)）（[官方文档《资料库》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Library)）（[官方文档《实践七：零代码制作本地应用》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Seven)）

## 阶段 6 自动化与远程

- **实验目的**：把“每周经营简报”配置为自动化任务，实践“先手动跑通 → 定时执行 → （可选）推送小程序”（官方实践五）。
- **前置条件**：完成阶段 2；电脑保持开机、WorkBuddy 运行、网络正常（运行前提详见第 7 章）。
- **操作步骤**：
  1. 手动跑通：先手动生成一份简报（示例指令：

     ```text
     请生成本周经营简报：销售概览、异常波动、下周建议
     ```

     ），确认输出格式与内容稳定。
  2. 创建自动化任务：按官方六项配置填写——名称（“每周经营简报”）、工作空间、提示词（沿用阶段 1 的分析要求并明确输出格式与异常处理）、选择模型和技能、定时规则（如每周一 9:00，设生效日期区间）、推送到小程序（○ 可选）。
  3. 低频率试运行：先以低频率验证，确认 Agent 理解与结果符合预期后再放大频率（官方《自动化》建议）。
  4. ○ 可选：通过手机微信/小程序查看推送结果。
- **预期结果与验收标准**：
  - 自动化任务按时触发，简报格式与手动版一致；
  - 执行过“先低频率试运行”的验证流程；
  - 简报内容含销售概览、异常波动与下周建议。
- **官方文档出处**：（[官方文档《自动化》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)）（[官方文档《实践五：每日自动推送资讯简报》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Five)）（[官方文档《WorkBuddy 小程序简介》](https://www.workbuddy.cn/docs/workbuddymini/quick-start/Overview)）

## 阶段 7 OPC 复盘与能力模型

- **实验目的**：复盘整个演练，映射超级个体“三层能力模型”（L1 单点放大 / L2 流程编排 / L3 系统自治，此为课程归纳框架，非官方文档定义），输出“我的 OPC 工作流”复盘文档。
- **前置条件**：完成阶段 0-6。
- **操作步骤**：
  1. 回顾阶段 0-6，列出每阶段用到的 WorkBuddy 能力（任务描述、文件/资料库、数据分析、人机双写、PPT、深度研究、轻量发布、自动化、助理等）。
  2. 映射三层能力模型：L1 单点放大（各阶段的单任务，如一次数据分析）、L2 流程编排（阶段间产物串联、阶段 6 的自动化任务）、L3 系统自治（构想：多 Agent + 自动化 + 定时深研的组合）。
  3. 找出可进一步自动化/编排的环节（如把深度研究也做成定时任务、用专家团复核报告、把简报推送到多端）。
  4. 输出“我的 OPC 工作流”复盘文档：能力清单、自动化地图、改进清单（≥2 条）。
- **预期结果与验收标准**：
  - 能力清单覆盖至少 5 类 WorkBuddy 能力；
  - L1/L2/L3 各举 1 个实例；
  - 改进清单 ≥2 条且可落地；
  - 复盘文档可分享（可作为结课答辩材料）。
- **官方文档出处**：教材第 9 章 §9.6（OPC 概念与超级个体，课程归纳框架，非官方定义）。
