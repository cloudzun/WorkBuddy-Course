## 实验 4.1 技能市场与管理

- **实验目的**：熟悉技能板块的两大区域（技能市场 / 已安装），掌握一键安装、启用/关闭、搜索、卸载等管理操作，并建立官方口径下的安全使用意识。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. 进入技能板块。技能（Skill）为 WorkBuddy 增加「特定工具能力」——封装一组可执行的脚本与工作流，使 AI 在您的授权下完成具体动作（如发送邮件、订外卖、查询股价、读写文件、调用第三方 API 等）。页面分为两个区域：
     - **技能市场**：推荐技能，可按需一键安装；
     - **已安装**：已安装的本地技能，可直接在对话中调用。
     （入口与区域划分以产品实际界面为准，[官方文档《技能》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)）
  2. 在「技能市场」推荐区浏览技能，选择一个**官方推荐技能**，点击后一键安装，确认其出现在「已安装」区域。
  3. **搜索**：技能较多时，通过「已安装」区域的搜索框输入关键词，快速定位目标技能。
  4. **启用 / 关闭**：已安装技能支持随时关闭或重新启用，**无需卸载**；关闭后该技能不会在对话中被调用。操作：先关闭某个技能，再在对话中发起原本会触发它的任务，确认不再被调用；随后重新启用并再次发起同类任务，确认恢复调用。
  5. **卸载**：需要在本机完全卸载技能时，选择「卸载技能」（支持批量操作卸载）。
  6. **安全认知**（建议，必做实验的一部分）：官方明确提示——**非官方 Skill 可能存在恶意提示词注入、越权访问、后门程序等隐患，请优先使用官方推荐 Skill**；安装第三方 Skill 前，请仔细查看其权限申请、来源说明与脚本内容，确认数据外发范围与可信度。Skill 调用第三方、修改本地文件、执行系统命令时，均以您本人身份执行；涉及文件删除、批量写入、系统配置变更或资金类操作时，建议先在小范围验证后再放大使用。
- **预期结果与验收标准**：
  - 能独立完成「一键安装 → 搜索定位 → 启用/关闭 → 卸载」全流程；
  - 关闭的技能不再被 AI 自动调用，重新启用后恢复；
  - 能复述官方建议：“仅启用当前任务所需的技能，减少无关干扰并降低误调用概率”；不确定是否保留时先关闭而非卸载；
  - 能说出官方安全提示（优先使用官方推荐 Skill；安装第三方前校验来源、权限申请与脚本内容）。
- **官方文档出处**：（[官方文档《技能》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)）

## 实验 4.2 技能调用验证

- **实验目的**：从官方“零成本 Skill 精选 10 个”中选用具体技能，通过实际任务触发技能，验证“先调用工具、再整理回答”的调用链路（工具函数 + 参数推理 + 结果整合），并对比技能调用与普通对话的差异。
- **前置条件**：完成实验 4.1；已安装并启用至少一个零成本技能（推荐从 Web Search、办公文档四件套、Local Whisper 中任选一个或多个）。
- **操作步骤**（三选一，推荐全部体验）：
  1. **方案 A：Web Search（联网搜索）**
     - 确认 Web Search（安装名 `web-search`）已启用。官方说明：当问题涉及**最近、最新、现在**等时效性信息时，仅依赖模型记忆往往不够，Web Search 可以让 WorkBuddy **先搜索、再整理、再回答**。
     - 下达任务：

       ```text
       请用 Web Search 搜索今天 AI 行业的三条重要新闻并给摘要。
       ```

       （也可采用官方推荐指令：

       ```text
       请帮我搜索最近 1 个月 AI 办公工具领域的重要动态，整理成要点摘要，并附上来源链接。
       ```

       ）
     - 观察执行过程：技能是否被触发、检索主题与时间范围等参数是否被解析，输出是否来自搜索结果并附有来源链接（官方建议带时间范围提问、要求附带来源）。
  2. **方案 B：办公文档四件套（文档处理）**
     - 确认「办公文档四件套」已启用。官方说明：该技能内置指令为 **PDF｜DOCX｜PPTX｜XLSX**，可让 WorkBuddy 直接处理常见办公文件，覆盖读取、生成、清洗、重组与导出等动作；能力概览：`pdf` 抽正文、抽表格、OCR、拆分合并、表单处理；`docx` 生成文档、整理结构、补目录、补页码、处理批注与修订；`pptx` 读取现有幻灯片、总结每页内容、压缩结构、重做演示文稿；`xlsx` 清洗表格、补公式、整理列、输出汇总结果。
     - 准备一个办公文件（PDF / DOCX / PPTX / XLSX 均可），对文件下达任务，例如：

       ```text
       解析这份 PDF 并提取关键数据与表格
       ```

       （或按文件类型要求生成 Word 文档、总结 PPT 每页内容、清洗 Excel 并补公式做汇总）。
     - 观察输出是否来自文件处理结果（提取的正文/表格、生成的新文件、汇总结果），而非模型凭空猜测。官方建议：遇到什么文件就用对应 Skill，并明确输出结果。
  3. **方案 C：Local Whisper（语音转文字）**
     - 确认 Local Whisper（安装名 `local-whisper`）已启用。官方说明：用于**本地语音转文字**，模型下载完成后即可离线运行，无需额外依赖在线转写接口，适合处理会议录音、语音备忘录、课程音频和访谈素材。
     - 提供一段音频文件（如会议录音或语音备忘录），下达官方推荐指令：

       ```text
       请把这段会议录音转成文字，并整理成会议纪要，包含主要结论、行动项和负责人。
       ```
     - 观察转写结果与纪要整理输出（官方建议：尽量提供清晰音频，转写后可继续衔接纪要整理、摘要提炼和待办生成）。
  4. **总结对比**：对比“技能调用”与“普通对话”在**一致性、可重复性、能力边界**上的差异；结合官方提醒理解积分成本——**涉及复杂的任务和复杂的 Skill 时，积分消耗通常较高**。
- **预期结果与验收标准**：
  - 任务执行中出现技能调用迹象（技能被触发、参数被解析、输出依赖工具结果而非纯模型猜测）；
  - 方案 A 输出含时效信息与来源链接；方案 B 输出与文件内容一致；方案 C 输出为可用的转写稿与纪要；
  - 能用一句话说明技能的价值：“Skill 是能力”——让 AI 能做某件事，并复述技能与普通对话在一致性、可重复性、能力边界上的差异。
- **官方文档出处**：（[官方文档《技能》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)）（[官方文档《零成本 Skill 精选 10 个》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10)）（[官方文档《Web Search》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Web-Search)）（[官方文档《办公文档四件套》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Office-Document-Suite)）（[官方文档《Local Whisper》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Local-Whisper)）

## 实验 4.3 技能的三种安装方式

- **实验目的**：逐一验证官方「添加技能」入口下的三种安装方式——**上传技能**（导入本地技能包安装）、**查找技能**（输入任务描述，WorkBuddy 自动查找相关技能）、**创建技能**（输入任务描述，WorkBuddy 自动创建相关技能），其中「创建技能」结合官方《实践八：自我进化—创建自己的 Skills》完成一次“一句话生成技能包并安装使用”的闭环。
- **前置条件**：完成实验 4.1。
- **操作步骤**：
  1. **打开安装入口**：点击「添加技能」，官方提供三种方式：上传技能、查找技能、创建技能（入口选项以产品实际界面为准）。
  2. **查找推荐（查找技能）**：选择「查找技能」，输入任务描述（如：

     ```text
     我需要一个能做网页抓取的技能
     ```

     ），由 WorkBuddy 自动查找相关技能，按提示完成安装，确认技能出现在「已安装」区域。
  3. **对话式创建（创建技能，自我进化）**：按官方《实践八》场景与步骤操作：
     - 选择「创建技能」，在对话框中直接说明你想要的能力、触发方式和输出结果。官方示例指令：

       ```text
       请帮我创建一个用于记录灵感的自定义 Skill。当我输入灵感、想法或待验证创意时，自动识别内容类型，整理成结构化记录，并保存到指定目录。
       ```
     - 执行完成后，打开技能栏，在「已安装」目录下即可查看新创建的 Skill。
     - **使用效果验证**：创建完成后，在任意对话中直接使用自然语言触发该能力。官方示例指令：

       ```text
       记一条灵感：做一个能自动整理会议纪要并同步到知识库的工具。
       ```

       观察 WorkBuddy 自动完成：识别这是一条灵感类内容 → 将内容整理为结构化记录 → 保存到指定位置并反馈记录结果。
     - 结合官方使用建议自查：先定义单一能力（首个自定义 Skill 只解决一个明确问题）、把触发条件说清楚（何时触发、写入哪里、输出什么结果）、从高频动作开始。
  4. **上传导入（上传技能）**：选择「上传技能」，拖拽或点击「选择文件」，选中本地技能包即可完成导入；导入后系统将自动完成配置，无需额外操作。（本地技能包的打包格式、目录结构等以产品实际要求为准。）
  5. **安全校验（建议）**：安装第三方技能前，官方建议优先使用官方推荐 Skill；可选用零成本技能 Skill Scanner 在安装前对 Skill 做安全审查，帮助发现可疑依赖、硬编码配置和潜在风险，降低误装风险（官方建议“先审查，再安装”）。
- **预期结果与验收标准**：
  - 三种方式都能成功安装技能，并出现在「已安装」区域；
  - 对话式创建生成的技能可被自然语言触发，并完成“识别 → 整理 → 保存 → 反馈”的完整闭环；
  - 上传导入的技能能正常启用（导入失败时能根据提示检查本地技能包）；
  - 能复述《实践八》的核心价值：把重复出现的个人工作习惯、知识处理方式和任务逻辑沉淀为可复用能力。
- **官方文档出处**：（[官方文档《技能》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)）（[官方文档《实践八：自我进化—创建自己的 Skills（技能）》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Eight)）（[官方文档《Skill Scanner》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Skill-Scanner)）

## 实验 4.4 召唤专家

- **实验目的**：走通“打开专家中心 → 按行业分类浏览 → 查看专家卡片 → 确认积分 → 下达任务”的专家召唤流程，理解专家是「角色切换」机制（以“人设 + 方法论 + 工具链”让 WorkBuddy 用特定领域专家身份执行任务）。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. **进入专家中心**：在左侧边栏点击「专家」，打开专家板块。专家板块包含**专家中心**和**我的专家**：在专家中心的专家和专家团支持**按行业分类浏览**，召唤他们为你服务；在我的专家创建属于你的专家，分享专业知识（入口与分类以产品实际界面为准，[官方文档《专家》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center)）。
  2. **浏览与筛选**：按行业分类浏览或使用搜索定位所需领域，找到感兴趣的专家/专家团。**专家卡片**展示能力介绍、擅长领域和任务示例；**专家团卡片**展示能力介绍、擅长领域、团队成员和任务示例。
  3. **评估卡片并确认成本**：阅读卡片内容，确认该实体的能力匹配度；留意积分消耗提示——**专家团会并行调用多位专家、涉及多轮模型交互，积分消耗通常为单专家的 3–5 倍（以实际任务为准）**；召唤前关注积分余额，避免任务执行中途因积分不足而中断。
  4. **下达任务**：点击「召唤专家」/「召唤专家团」，进入对话界面，用自然语言描述任务，例如：

     ```text
     请以数据分析专家的身份，帮我设计一份销售看板的数据指标清单。
     ```

     将任务告诉 WorkBuddy，其将会按照该角色的专业视角和方法完成任务。
  5. **观察输出**：核对专家输出是否体现其人设与方法论（与普通对话风格有可辨识差异）。同步建立两个官方认知：**专家本身不主动获取系统权限，仅处理您主动提供的对话与上传文件；当配备了 Skill / MCP 时才会在您的授权下间接访问文件或外部服务**；WorkBuddy 生成内容仅供参考，不构成专业意见，涉及医疗、法律、投资、合规等重大决策建议咨询专业人士。
- **预期结果与验收标准**：
  - 完整走完“浏览筛选 → 评估卡片 → 确认成本 → 下达任务”的召唤流程；
  - 专家输出体现其人设与方法论，与普通对话风格有可辨识差异；
  - 能解释“Skill 是能力、专家是能力 + 经验”的定位差异，并说出专家的「人设 + 方法论 + 工具链」三要素。
- **官方文档出处**：（[官方文档《专家》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center)）

## 实验 4.5 专家团与 Multi-Agent（可选）

- **实验目的**：验证专家团的「协作执行」机制——由多位专家分工协作，团长自动拆解、并行执行并整合交付——并对比专家团与单个专家的积分消耗差异。
- **前置条件**：完成实验 4.4；确认账户积分充足（专家团会并行调用多位专家、涉及多轮模型交互，**积分消耗通常为单专家的 3–5 倍（以实际任务为准）**；召唤专家团前请关注积分余额，避免任务执行中途因积分不足而中断）。
- **操作步骤**：
  1. 在专家中心选择一个专家团（如产品设计类、技术工程类），先查看其卡片上的能力介绍、擅长领域、团队成员和任务示例，确认适配度。
  2. 点击「召唤专家团」，进入对话界面，用自然语言描述一个跨步骤的复杂任务（如“从市场定位到高保真原型输出”）。
  3. 观察执行过程：**团长是否先理解需求并自动拆解子任务 → 按专家专长分配 → 并行执行 → 最终统一整合并返回完整结果**。
  4. 对比验证：用同一个任务分别召唤单个专家与专家团，记录两者的积分消耗与产出完整性差异。
- **预期结果与验收标准**：
  - 能看到多 Agent 协作迹象（任务拆解、分工分配、整合交付的输出结构）；
  - 专家团产出覆盖多个专业环节，完整度优于单专家；
  - 能确认专家团积分消耗显著高于单专家（官方口径：通常为单专家的 3–5 倍）；
  - 能解释“专家团是多位专家 + 协作流程”，适合任务复杂、需要多角色配合的场景。
- **官方文档出处**：（[官方文档《专家》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center)）

## 实验 4.6 创建自定义专家（可选）

- **实验目的**：在「我的专家」中创建一个属于自己的自定义专家（专家 Agent 或专家团 Team，类型与字段约束以产品实际界面为准），理解其价值——沉淀个人/团队的最佳实践，并分享专业知识。
- **前置条件**：完成实验 4.4。
- **操作步骤**：
  1. 进入「我的专家」，开始创建流程。官方将专家定义为「角色切换」机制：以**人设 + 方法论 + 工具链**让 WorkBuddy 用特定领域专家身份执行任务；参考该定位，按创建向导配置你的人设设定、处理方法（方法论）与常用工具链（具体字段名称、必填项与约束以产品实际界面为准）。
  2. 若需要沉淀个人经验：参考《实践八》的思路，把你反复使用的任务处理方式、输出格式与偏好整理进专家配置，让自定义专家在后续任务中直接复用。
  3. 保存后用该自定义专家执行一个小任务，验证其行为符合设定（输出风格、方法论是否与设定一致）。
  4. 分享（可选）：官方介绍“在我的专家创建属于你的专家，分享专业知识”；若产品提供分享入口，可尝试生成分享入口或分享链接（分享能力与入口以产品实际界面为准）。
- **预期结果与验收标准**：
  - 自定义专家创建成功并可被调用；
  - 该专家的输出风格与方法论与设定一致；
  - 能说明自定义专家的价值：把个人/团队的优秀实践沉淀为可复用专家，并支持分享专业知识。
