## 实验 3.1 灵感大厅探索

- **实验目的**：熟悉灵感模块的入口与浏览方式，理解灵感 = 由 WorkBuddy 生成或社区贡献的优质内容所组成的精选成品集（Prompt + Skill + 专家配置），并了解灵感与 Skill、专家的定位区别。
- **前置条件**：完成实验 1.1。
- **操作步骤**：
  1. 进入灵感：在 WorkBuddy 左侧边栏点击“更多”，进入“灵感”入口。官方概述为“不知道从哪开始？打开灵感，浏览大家做出的 WorkBuddy 精选成品”。
  2. 浏览案例：进入灵感大厅后，可在“精选板块”随机选择热门案例，或按“场景分类”搜索案例。官方口径为“精心打磨的七大场景，覆盖日常和工作中的高频需求”，具体分类名称与列表布局以产品实际界面为准。
  3. 选择与你工作或学习相关的 1-2 个场景分类，浏览该分类下的案例列表，感受“按需挑选，无需从零定义”的浏览方式。
  4. 打开案例详情：点击所选案例，查看案例预览、所使用的工具集和详情介绍（左侧运行预览、右侧标签与背景介绍的具体排布以产品实际界面为准）。
  5. 收藏案例：发现感兴趣的“宝藏案例”，点击“红心”图标收藏（收藏列表的入口位置以产品实际界面为准）。
  6. 对照官方口径梳理三个模块的定位：Skill＝“WorkBuddy 能做什么”，专家＝“WorkBuddy 中的谁能帮我做”，灵感＝“用这些能力实际做出了什么”，并用自己的话说出“灵感是什么”。
- **预期结果与验收标准**：
  - 能独立通过“左侧边栏 → 更多 → 灵感”找到入口并完成一次浏览；
  - 能说出官方“七大场景”的口径，并指出至少一个与自身需求相关的场景分类；
  - 能打开案例详情，指出案例预览、所用工具集与详情介绍所在位置（以产品实际界面为准）；
  - 红心收藏成功后，能在收藏列表中找到该案例；
  - 能说出一句“灵感是什么”：灵感集中陈列由 WorkBuddy 生成或社区贡献的优质内容，供查看、收藏与“做同款”，本质是“别人做好的成品集（Prompt + Skill + 专家配置）”。
- **官方文档出处**：（[官方文档《灵感》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Ispiration)）

## 实验 3.2 “做同款”一键复刻

- **实验目的**：通过“做同款”跑通“选择案例 → 自动预填 → 微调 → 生成查看”的完整流水线，观察 Prompt、Skill 与专家配置的自动就位，验证“一键复刻，告别空白页”与“节省 Token，更高性价比”的官方价值主张。
- **前置条件**：完成实验 3.1。
- **操作步骤**：
  1. 回到灵感大厅，选择与实验 3.1 中收藏案例同类型的一个案例，进入其详情页。
  2. 点击“做同款”（官方“如何使用灵感”中的对应按钮文案为“制作我的版本”），观察 WorkBuddy 自动把该案例的 Prompt 预填到对话框，并自动加载关联的 Skill 与专家配置——全程无需手工配置（自动加载的具体呈现形式以产品实际界面为准）。
  3. 按官方提示可“直接生成”，或“修改细节生成你的专属版本”：结合自己的需求对预填 Prompt 做少量微调（如替换具体对象、期限、输出格式等），修改后发送。
  4. 在右侧产物页面查看生成结果；若生成的是网页文件，WorkBuddy 会自动打开内置浏览器预览效果，其他类型产物按对应形式展示。
  5. 留意“做同款”会触发对应的 Skill / 专家，由对应模块继续完成任务；复现案例时请关注所触发 Skill / 专家的能力边界与权限申请，积分消耗以实际触发的功能模块为准（浏览本身不涉及积分消耗）。
- **预期结果与验收标准**：
  - 点击“做同款”后，Prompt 自动预填、Skill 与专家配置自动就位，全程无需手工配置；
  - 微调后一次生成即得到可用产物；
  - 能在右侧产物页面查看结果，网页类产物可经内置浏览器预览；
  - 能复述“做同款”的完整流程：进入灵感 → 选择案例 → 做同款（Prompt / Skill / 专家自动就位）→ 微调 → 生成并查看产物。
- **官方文档出处**：（[官方文档《灵感》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Ispiration)）

## 实验 3.3 灵感 vs 从零创建对比

- **实验目的**：量化对比“灵感复刻”与“从零写任务”两种方式的配置时间、追问次数与产物质量，验证灵感“一键复刻、节省 Token、社区智慧沉淀”等优势，并结合第 2 章三要素公式说明灵感本质是“别人写好的三要素样板”。
- **前置条件**：完成实验 2.1（三要素公式）与实验 3.2。
- **操作步骤**：
  1. 选定同一个任务目标（如：

     ```text
     生成一份竞品分析周报
     ```

     ），并先用三要素公式把任务拆解清楚：做什么（生成竞品分析周报）、有什么（竞品数据、参考文档等输入）、怎么样（输出格式、篇幅、风格、期限等约束）。从零创建时可参照官方《创建任务》页面的建议补充上下文：@ 引用文件、上传文件、粘贴截图，以及明确“目标、输入、输出格式、约束条件”等信息。
  2. 方式 A（从零创建）：新建任务，不借助灵感，按三要素公式自己撰写任务描述并补充上下文；记录任务描述撰写耗时、追问/调整轮数、Token 消耗感受、产物质量与返工情况。
  3. 方式 B（灵感复刻）：回到灵感大厅，选择与任务目标同类型的案例，点击“做同款”，把自动预填的 Prompt 微调成与方式 A 一致的目标后生成并查看产物；记录与方式 A 相同的指标。
  4. 对比两种方式的指标，填入对比记录（示例：指标 | 方式 A 从零创建 | 方式 B 灵感复刻；至少包含配置时间、追问次数、Token 消耗感受、产物质量四行）。
  5. 结合第 2 章三要素公式与官方“灵感 = 用这些能力实际做出了什么”的口径解释对比结果：灵感本质是“别人写好的三要素样板”，案例作者已把“做什么 / 有什么 / 怎么样”打磨完成，复刻时只需微调，因此配置时间更短、追问更少。
- **预期结果与验收标准**：
  - 方式 B 的配置时间显著更短、追问更少，符合官方“一键复刻，告别空白页”与“节省 Token，更高性价比”的说明；
  - 两种方式产物质量相当，或方式 B 更稳定（可参考《10 个上手技巧》第 6 条“给 WorkBuddy 看例子，比说一堆要求更管用”）；
  - 能结合三要素公式解释“灵感 = 别人写好的三要素样板”，并正确复述三个模块的定位：Skill＝“能做什么”、专家＝“谁能帮我做”、灵感＝“实际做出了什么”；
  - 对比记录完整（配置时间、追问次数、产物质量至少各记录一项）。
- **官方文档出处**：（[官方文档《灵感》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Ispiration)）（[官方文档《WorkBuddy 10 个上手技巧》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Efficient-Tips)）
