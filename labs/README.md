# WorkBuddy 课程配套实验手册

> 本目录收录与《WorkBuddy 效率进阶实训课程教材》配套的实验，用于**验证各章知识点与产品功能点**。第 1-8 章为知识点/功能点验证型实验，第 9 章为贯穿式综合演练（咖啡品牌季度经营分析项目）。

## 使用说明

- **实验文件**：`ch01-labs.md` ~ `ch09-labs.md`，与教材章节一一对应（第 9 章为综合演练）。
- **实验编号**：`章号.实验号`（如 2.1 表示第 2 章第 1 个实验），便于与教材小节对应与引用。
- **类型图例**：
  - **★ 必做实验**：仅需 WorkBuddy 基础环境（已安装并登录），是核心知识点的必要验证；
  - **○ 可选实验**：需要额外账号/权限/配置（连接器授权、模型 API、企业微信管理员、开发者认证等），前置条件在实验中已标注。
- **环境要求**：Windows 10+ / macOS 12+ 电脑；实验前先完成第 1 章实验 1.1（安装、扫码登录、连通性自检）。
- **依赖关系**：部分实验依赖前一实验的产物或授权（已在“前置条件”中标注），建议按章内顺序完成。
