任务描述的黄金法则
三要素公式：做什么 + 有什么 + 怎么样
明确目标与可量化的验收标准
提供上下文、消除歧义
样板文件技巧
三要素公式：做什么 + 有什么 + 怎么样
做什么
明确核心动作与目标
（整理、生成、分析……）
有什么
提供输入素材与前置条件
（文件、数据、参考）
怎么样
指定输出格式与质量标准
（表格 / 条数 / 风格）
示例指令（官方正面示范）
把 D:/会议纪要/0320产品评审.docx 里的会议纪要整理成一份清单，包含：
1）每个议题的结论；2）对应的责任人和截止日期；3）标记有争议、未决的事项。
用表格输出，不需要开场白。
最佳实践：指定输出格式时，直接挂载一份“样板文件”，系统按范式生成。
明确目标与验收标准
描述终点而非路线
重点向系统索要结果，不要过度规定中间的推演过程
提供可量化的“尺子”
字数限制、章节长度、层级结构、语言风格等验收标准
一次说清关键信息
读者身份、专有名词、负面清单（明确“不做什么”）
验收标准是“尺子”：越具体，产物越接近你想要的。
提供上下文与消除歧义
01
角色指代
把模糊人称替换为具体角色或姓名
02
时间要求
把“昨天 / 最近”替换为具体日期或时间范围
03
数量指标
把“一些 / 几个”替换为明确数字
04
质量标准
把“高大上 / 专业”转化为可验证的排版或语言规则
宏大多层级任务：拆解为有序独立步骤，配合 Plan 模式逐步攻克。

附件与上下文引用
四种上下文挂载方式

隐私授权边界
四种上下文挂载方式（官方文档《创建任务》）
@ 引用上下文
输入 @ 引用文件、文档、规则等信息，关联到任务
粘贴截图
Ctrl/Cmd + V 直接粘贴剪贴板图片，提供界面/图文信息
上传文件
点击上传按钮或拖拽本地文件（PDF、Excel 等）
补充说明
明确目标、输入、输出格式、约束条件等关键信息
四种方式可以混用：文本 + 文件拖拽 + 截图粘贴 + @引用，一次提问全部带上。
支持的文件类型（官方文档《任务对话》）
文档类
PDF / Word / TXT / Markdown / RTF
表格类
Excel / CSV / TSV
演示类
PPT
图片类
JPG / PNG / GIF / BMP
压缩包
ZIP / RAR
代码文件
各类编程语言源码
安全提示：文件夹级授权属高风险操作，遵循“最小权限”，只授权必要的项目子目录。
隐私授权边界与安全机制
所有文件处理默认在本地完成，原始数据不上传云端；服务端仅处理数据片段，用后即弃，不保存也不用于模型训练（官方文档《任务对话》）。
仅访问你主动勾选授权的文件夹，系统敏感目录自动拦截
高危操作需二次确认（删除、批量写入、系统配置变更等）
知识库引用：通过资料库/连接器按登录用户权限读取云端资料
隐私承诺：用后即弃，不保存、不用于模型训练——可放心处理敏感业务数据。

任务对话与追问技巧
闭环过程：输入 → 补充 → 执行 → 验收 → 追问
上下文保持与边界（固定锚点）
软修正与硬打断
分步确认与“追问 vs 新建”判断
对话闭环与上下文保持
输入需求
→
补充上下文
→
查看思考与执行
→
验收
→
追问调整
上下文保持：同一任务会话自动保留全部历史，追问无需重复前置条件；跨任务对话相互隔离。
实践技巧：长对话中用“固定锚点”——定期让 AI 总结已确认的阶段性成果，再继续下一轮（经验建议，官方未设轮数上限）。
追问只需说“改什么”：不用重复背景，WorkBuddy 接着上下文继续。
任务的打断与修正
软修正
生成完毕或停顿期间，发送新提示词把方向“拉回来”。
三类追问：
· 新需求：再加一个饼图
· 修改意见：表格按销售额排序
· 继续追问：帮我导出成 PDF
硬打断
任务执行中，输入框区域实时显示“停止入口”，可随时中断。
中断后三种继续方式：
· 补充新的说明
· 调整需求后重新发送
· 基于已有内容继续推进
执行过程全程透明：思考与步骤进度（Todo 清单）实时可见，随时监控推演方向。
分步确认与“追问 vs 新建”
分步确认（强依赖中间确认的任务，首选 Plan 模式）
长报告
先确认大纲，后填充细节
批量处理
先在一个测试文件上跑样例，验收后批量
代码重构
先讨论技术方案，再生成实施代码
判断标准：核心目标是否发生实质性变化
· 仍在完善初始任务 → 继续追问
· 产生全新灵感或独立子模块 → 果断新建任务
口诀：修补旧目标用追问，开启新目标用新建。

结果查看与产物交付
结果区四类内容：概览（工作空间文件 / 浏览器 / 变更 / 产物）
产物预览、下载与分享
交付五步检
结果区四类内容（官方口径：概览）
工作空间文件
树状浏览当前工作空间所有文件，快速对照定位
浏览器
内置轻量浏览器，实时预览网页 / UI 原型
变更
Diff 对比文本/代码修改，遵循“先看再接受”
产物
最终交付物聚合入口：免下载预览、下载、分享
检视是持续的：右侧视图随对话指令实时刷新迭代，无需离开任务流。
产物分享（上传云端 / 下载）
预览产物时点击右上角分享图标，可选择上传到云端协作载体，或下载到本地。
云端载体（需对应账号授权）
我的云端网盘
腾讯文档
ima 知识库
乐享知识库
分享后可到「设置-数据管理」的“我分享的文件”中复制链接 / 下载 / 取消分享。
产物交付前的“五步检”
01
完整性检查
信息是否截断？要求的字段是否都有体现？
02
符合预期
格式、语气、深浅程度是否与三要素约定相符？
03
敏感信息排查
是否包含需脱敏的 IP、姓名或商业机密？
04
分享方式选择
按接收者习惯选择源文件、PDF 或云文档链接
05
一句话说明
附上背景与核心结论，降低接收者阅读门槛
口诀：完整 → 达标 → 脱敏 → 选路 → 一句话。

工作空间与任务归档
工作空间 = 项目目录 + 任务集合 + 上下文配置
多任务并行与资源隔离
归档 vs 删除
工作空间与任务的容器关系
工作空间 = 具体的项目目录 + 相关的任务集合 + 沉淀的上下文配置
任务（Task）：一次具体的对话与产出，具有瞬时性、即战力
按项目粒度选目录
一个开发项目、一次年终总结，都拥有独立工作空间
两条收编路径
新建任务时直接挂载；或右键历史任务“保存到工作空间”
多端实时同步
以当前最新版本为准，任务状态流转与移交不间断
团队协作：把工作空间根目录放进 Git/SharePoint/腾讯文档同步目录，变更即触达团队。
多任务并行与资源隔离
任务级并行
不同任务独立运行、互不阻塞；新任务即开即建，边等边干，无需排队
上下文隔离
每个任务自带独立的对话、文件引用与配置，互不串扰
同空间内协作
同一工作空间的任务共享根目录，产物按任务维度归集，便于对照验收
任务状态六态：进行中 / 已完成 / 失败 / 待处理 / 规划中 / 已归档 —— 一眼定位每个并行任务的阶段。
搜索与筛选：支持按关键词检索历史任务，可按状态/时间快速过滤，长尾任务也能快速找回。
会话与资源：一次会话内可连续对话，也可直接新建任务转入新会话，资源配置按任务独立生效。
归档 vs 删除
对比项
归档（软清理）
删除（硬清理）
操作入口
任务右键 → 归档
任务右键 → 删除
确认方式
直接归档，可随时找回
二次确认，且不可恢复
产物状态
保留对话与产物，可重新打开
对话与产物不可再查看
后续能力
可继续对话、重新打开
无法查看、无法继续对话
适用场景
阶段性收尾，后续可能复用
确定废弃，彻底清理
⚠ 删除是高风险操作：二次确认后，对话与产物将不可查看、不可继续对话。重要任务请优先归档。
