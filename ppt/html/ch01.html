主界面与核心功能
主界面三大区域：导航 / 对话 / 结果
新建任务栏：工作模式、模型、技能、连接器、工作空间、权限
任务状态、结果区与专家体系
系统设置、数据管理与记忆管理
主界面三大区域
左侧导航
导航中枢：任务列表按「任务 / 空间」两板块分组，可搜索与筛选；底部个人头像入口
中间对话区
核心交互：任务标题栏、消息列表、输入框；底部新建任务栏集成关键配置入口
右侧结果区
成果展示：概览（工作空间文件 / 浏览器 / 变更 / 产物），四类内容集中查看
六种任务状态：进行中 / 已完成 / 失败 / 待处理 / 规划中 / 已归档（官方文档《任务管理》）。
新建任务栏：关键配置入口
工作模式
Ask / Craft / Plan，三大底层模式快速切换
模型选择
Auto / 混元 / GLM / MiniMax / Kimi / DeepSeek 等内置模型
工作空间
绑定特定工作目录，隔离项目文件与上下文
技能 Skill
指定任务调用能力：内置 20+ 技能包，兼容社区技能导入
连接器
接入外部系统或数据源（QQ 邮箱、腾讯文档等）
权限控制
默认权限或完全访问，高危操作二次确认
安全提示：修改系统级文件或敏感目录时谨慎使用“完全访问”；非信任插件保持最小权限。
专家中心：Skill / 专家 / 专家团
Skill（技能）
单一的、具体的操作能力
例如“解析 Excel”“网页抓取”
专家（Agent）
能力 + 经验：独立人设 + 方法论 + 工具链
系统内置大量领域专家（数量以产品界面为准）
专家团（Team）
多位专家组成的协作流程
团长 + 分工机制 + 协作网络，攻克大型项目
一句话速记：想要能力找技能；想要建议找专家；想要团队攻坚找专家团（召唤流程详见第 4 章实操）。
系统设置 / 数据管理 / 记忆管理
系统设置
语言、字体大小、显示模式（简洁模式）
非高风险 Skill 自动安装、防休眠
数据管理
“我分享的文件”：复制链接、下载保存、取消分享
记忆管理
生成对话记忆（默认开启，每晚自动整合）
手动管理、从其他 AI 产品导入记忆
记忆让 AI 更“懂”你：每晚自动生成记忆特征，使用习惯可无缝迁移。

三大工作模式：Ask / Plan / Craft
Ask：只读问答，绝不修改文件
Plan：先规划后执行，计划确认后才动手
Craft：直接执行，最高自动化
模式选择：安全性 × 自动化程度的平衡
Ask 模式：纯问答（Talk only, hands off）
功能特点：只读交互，仅提供问答服务，绝对不会修改您的任何本地文件；所有输出仅限于对话框内的文字回复。
适用场景
了解内容
快速阅读长篇文档并提取摘要
确认需求
动手前探讨技术方案或文章大纲
安全审视
检查代码漏洞、文章错别字，由你决定是否采纳
推荐理由：零风险——最适合处理敏感文件或初步的想法探索。
Plan 模式：先规划后执行（Think first, do second）
功能特点：不会立即修改，先生成详尽的执行计划（Todo List / 执行计划书）供您审核；确认并点击“执行”后才开始文件读写与操作。
适用场景
多步骤任务
分析年度财报 → 提取关键指标 → 生成汇报 PPT
审阅改动范围
代码重构、批量文件重命名：先看计划防意外损坏
讨论协作
不确定步骤时，通过 AI 的规划获得灵感并调整方向
推荐理由：安全可控——处理复杂任务或批量修改工作时的首选模式。
Craft 模式：直接执行（You say, I do）
功能特点：最高自动化级别——“数字员工”的核心模式。具备完整文件读写权限，跳过计划确认，直接在工作空间创建、修改或删除文件。
适用场景
文档生成
几句提示词快速生成请假条、通告
表格处理
对指定数据进行格式化、求和或透视
文件整理
桌面图片按日期分类放入对应文件夹
推荐理由：效率最高——适合日常高频常规操作或对结果有绝对把握的任务。
