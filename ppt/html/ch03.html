什么是灵感
灵感 = 一个完整的灵感案例：经过验证的 Prompt + 关联的 Skill + 特定领域的专家配置
面向“不知如何向 AI 提问”或“难以配置最佳工具组合”的用户，灵感大厅汇聚了社区精选成品集。
观察窗口
看到已打磨好的真实作品案例，了解“好方案长什么样”
一键复刻
点击“制作我的版本”，Prompt / Skill / 专家配置全部自动就位
省时省钱
免去从零设计 Prompt 的时间与试错消耗的 Token 成本
一句话：灵感是“别人做好的成品”，你可以直接拿走，而不是从零开始。
一个灵感案例里的“三件套”
一个完整的灵感案例由三部分自动组装而成，复刻时无需手工配置：
Prompt（提示词）
怎么对话
经过验证的高质量指令：角色设定、约束条件、结构化指令、少样本示例
Skill（技能）
能做什么
案例依赖的具体能力：网页抓取、代码运行、数据处理等
专家配置
谁来帮我
特定领域的专家角色：提供专业视角与系统性方法论
复刻瞬间：Prompt 自动预填对话框，Skill 与专家配置在后台自动加载，开箱即用。

收益：输出高质量与稳定性兼得，并省去反复修改提示词、多次试错的 Token 成本。
高质量提示词的四要素
灵感模板之所以高效，是因为内部包含了一条结构完整的高质量指令：
角色设定
让模型以特定身份/视角作答，如“资深数据分析师”
约束条件
限定范围、风格、字数、格式等边界，防止跑偏
结构化指令
按“背景 → 任务 → 格式 → 约束”的逻辑组织要求
少样本示例
给出 1-2 个范例，让模型“照着样子做”
任务描述的完整方法论见第 2 章——三要素公式（做什么 + 有什么 + 怎么样）。

3.3
灵感、技能与专家的关系预览
技能（Skill）：能做什么 —— 具体的“能力”或“工具”
专家：谁能帮我做 —— “能力 + 经验”的专业角色
灵感：做出来是怎样的 —— 最终的“成品”或“作品”
为第 4 章逐一拆解技能、专家与专家团建立认知锚点
核心差异速记
技能 Skill
能做什么
工具属性，提供底层能力：
网页抓取、代码运行、翻译、格式转换等
专家
谁能帮我做
角色属性，能力 + 经验：
专业视角与系统性方法论，如架构师规划系统
灵感
做出来是怎样的
成品属性，完整解决方案：
有目标但不知从哪开始时的现成方案
定位差异：技能回答“能做什么”，专家回答“谁能帮我做”，灵感回答“做出来是怎样的”。
本章先以“成品”视角理解三者关系，第 4 章将逐一拆解完整机制。

组合使用更高效：用灵感起步 → 用专家把关 → 用技能落地，一条流水线通吃。
