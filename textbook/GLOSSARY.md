# WorkBuddy 教材术语表（Glossary）

> 全书统一术语对照。首次出现时给出中英对照，后续统一使用本表译法。

| 英文术语 | 中文译法 | 说明 | 首次出现 |
|---|---|---|---|
| WorkBuddy | WorkBuddy | 产品名，不翻译 | 第 1 章 |
| Ask Mode | Ask 模式（问一问） | 三种工作模式之一：只读问答 | 第 1 章 |
| Craft Mode | Craft 模式（做一做） | 三种工作模式之一：直接执行 | 第 1 章 |
| Plan Mode | Plan 模式（想一想） | 三种工作模式之一：先规划后执行 | 第 1 章 |
| Skill | 技能 | AI 工具函数/能力包 | 第 1 章 |
| Agent | 专家 | 单个 AI 智能体 | 第 1 章 |
| Team | 专家团 | 多 Agent 协作团队 | 第 1 章 |
| Expert Center | 专家中心 | 专家/专家团管理入口 | 第 1 章 |
| Connector | 连接器 | 基于 MCP 的外部服务桥梁 | 第 1 章 |
| MCP | MCP（Model Context Protocol） | 模型上下文协议 | 第 5 章 |
| Function Calling | 函数调用 / 工具调用 | AI 调用工具的机制 | 第 4 章 |
| Claw / Assistant | 助理 | 远程操控功能（详解见第 7 章） | 第 1 章 |
| Workspace | 工作空间 | 项目目录 + 任务集合 + 上下文配置；统一译法，不写“工作区” | 第 1 章 |
| Artifact | 产物 | 任务生成的交付文件；统一译法，不写“产出物” | 第 1 章 |
| Inspiration | 灵感 | 社区精选成品集 | 第 3 章 |
| Library | 资料库 | 文档集成模块 | 第 2 章 |
| Automation | 自动化 | 定时任务功能 | 第 8 章 |
| Token Plan | Token Plan | 按 Token 用量计费方式（详解见第 6 章） | 第 1 章 |
| Coding Plan | Coding Plan | AI Coding 专属订阅（详解见第 6 章） | 第 1 章 |
| Ollama | Ollama | 本地大模型部署工具（详解见第 6 章） | 第 1 章 |
| OPC | OPC（One Person Company） | 一人公司（详解见第 9 章） | 第 1 章 |
| OAuth | OAuth | 开放授权协议 | 第 5 章 |
| WebSocket | WebSocket | 长连接通信协议 | 第 7 章 |
| Multi-Agent | Multi-Agent（多智能体） | 多 Agent 协作架构 | 第 4 章 |
| 积分 | 积分 | WorkBuddy 使用额度 | 第 4 章 |
| 提示词 | 提示词 / Prompt | 用户输入的任务描述（详解见第 2 章） | 第 1 章 |
