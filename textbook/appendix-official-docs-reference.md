## A.3 课程与官方文档的差异说明

1. **侧重点差异**：官方文档侧重于功能入口、按钮定义和基本配置；本课程侧重于“如何用”，即如何将功能组合以解决真实的业务痛点。
2. **术语规范**：本课程全程采用统一的规范术语，如统一使用“工作空间”、“产物”、“连接器”（见术语表）。
3. **内容拓展**：人机双写、设计创意模式以及轻量发布（本地 HTML 一键发布为 workbuddy.link 在线链接）等官方文档近期新增能力，本课程已将其融入典型场景实战章节。
