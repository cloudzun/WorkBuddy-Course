# 第 3 章 灵感模块

> 面对 AI 工作台，很多人最大的障碍不是“不会用”，而是“不知道从哪开始”。灵感模块正是为消除这份空白恐惧而生：它汇聚了社区验证过的优秀成品（Prompt + Skill + 专家配置），你只需一键复刻，就能立刻跑通一条完整的 AI 工作流水线——这也将直观地带出本书后面要逐一拆解的核心概念与方法。

## 学习目标

学完本章，你应该能够：
1. 理解灵感模块的核心价值与底层执行链路。
2. 熟练掌握从探索案例到一键复刻的完整操作流程。
3. 理解灵感、技能与专家的定位差异，为后续章节的能力拆解建立认知锚点。

## 3.1 灵感模块概述

### 3.1.1 什么是灵感

在日常办公与开发中，许多用户常常面临“不知如何向 AI 提问”或“难以配置出最佳工具组合”的困境。WorkBuddy 的灵感模块正是为了解决这一痛点而生。一句话理解灵感：它是一个完整的灵感案例，内部包含了经过验证的 Prompt（提示词）、关联的 Skill（技能）以及特定领域的专家配置。

灵感模块汇聚了 WorkBuddy 用户的精选成品集。对于新手或希望提升效率的用户而言，这里是观察已打磨好的真实作品案例的最佳窗口。当你发现符合需求的案例时，只需点击“制作我的版本”即可一键复刻。在这个过程中，Prompt、Skill 和专家配置会全部自动就位，极大地省去了从零设计 Prompt 的时间以及试错所消耗的 Token 成本。

### 3.1.2 灵感为何能“开箱即用”

要理解灵感模块的价值，需要知道一条高质量的指令通常包含角色设定、约束条件、结构化指令（按背景、任务、格式、约束的逻辑展开）以及少样本示例等要素（任务描述的完整方法论见第 2 章）。在底层，可以将 AI 的执行过程理解为“用户输入 → 提示词组装 → 模型推理 → 结果整合”的链路，其中提示词组装阶段会将用户的输入、系统预设提示、相关 Skill 的描述以及连接器能力进行有机融合（该链路为教材对产品执行逻辑的教学化概括）。

灵感模板正是把这一组装环节的最优配方（Prompt + Skill + 专家配置）固化了下来，使模型在推理时能够直接沿最优路径运行，从而保障输出结果的高质量与稳定性，并省去了反复修改提示词和试错所消耗的 Token 成本。

### 3.1.3 功能优势

灵感模块具备以下四大核心优势：
- **场景全覆盖**：无论你身处哪个行业或岗位，都能找到对应的灵感案例，满足多样化的业务需求。
- **节省 Token 成本**：避免了反复修改提示词和多次试错带来的资源消耗。
- **一键复刻**：复杂配置瞬间就位，将原本需要几十分钟的配置工作压缩至几秒钟。
- **社区智慧沉淀**：汇聚了平台上最优秀的使用经验与创意，是一个不断进化和生长的知识库。

## 3.2 灵感模块操作指南

### 3.2.1 探索与查找灵感

想要寻找合适的灵感，你需要进入灵感大厅。
1. 在 WorkBuddy 界面中，点击左侧边栏的“更多”选项。
2. 在弹出的菜单中，点击“灵感”即可进入灵感模块主页。

> 📷 请参见产品界面：[左侧边栏 -> 更多 -> 灵感]

在灵感大厅中，所有案例均按实际业务场景进行了精细分类。官方文档将其概述为“精心打磨的七大场景，覆盖日常和工作中的高频需求”（[官方文档《灵感》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Ispiration)）；具体类别名称与数量以产品内实际展示为准（当前最新版本）。

### 3.2.2 预览与评估

当你对某个案例感兴趣时，点击即可进入案例卡片详情页。
页面左侧会展示该灵感案例的实际运行预览效果，让你直观地看到“它能做出什么”。页面右侧则包含了该案例的标签分类以及详细的背景介绍。如果你觉得该案例非常有价值但暂时还不需要使用，可以点击红心图标进行收藏，方便日后随时取用。

### 3.2.3 一键复刻与制作

选定心仪的灵感后，即可开始制作属于你的版本。
1. 在案例详情页，点击“做同款”按钮。
2. 系统会自动将该案例的 Prompt 预填至你的对话框中。
3. 同时，系统在后台会自动加载该案例所需的 Skill 和专家配置。
4. 此时，你可以根据自己的实际需求对预填的 Prompt 进行微调，或者直接发送指令开始生成。

### 3.2.4 查看与管理产物

生成完成后，如何查看和管理这些产物呢？
最终生成的内容会展示在界面右侧的产物页面中。对于网页、文档等特殊格式的产物，你可以使用内置浏览器进行即时预览。如果需要进一步处理，系统也支持将产物下载到本地继续编辑，或者将其保存至你的工作空间中。

## 3.3 灵感、技能与专家的关系预览

### 3.3.1 核心差异速记

在 WorkBuddy 中，灵感、技能（Skill）与专家虽然都是提升效率的工具，但它们的定位和适用场景有着显著的差异。本章先以“成品”的视角理解三者关系，下一章将逐一拆解技能、专家与专家团的完整机制。

- **技能（Skill）**：代表着具体的“能力”或“工具”，回答的核心问题是“能做什么”。适合当你清楚知道自己需要某种特定工具能力（如网页抓取、代码运行）时的场景。
- **专家**：代表着“能力 + 经验”，回答的核心问题是“谁能帮我做”——找到具备专业视角和系统性方法论指导的角色（[官方文档《灵感》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Ispiration)）。适合当你需要专业视角和系统性方法论指导（如需要一位架构师帮你规划系统架构）时的场景。
- **灵感**：代表着最终的“成品”或“作品”，回答的核心问题是“做出来是怎样的”。适合当你有一个目标但不知道从哪开始，或者希望直接获取现成解决方案的场景。

一句话速记它们的区别：**想要能力找技能；想要建议找专家；想要成品找灵感**。

### 3.3.2 场景选择速查

| 功能模块 | 核心特征 | 适用场景 | 推荐建议与选择技巧 |
| :--- | :--- | :--- | :--- |
| 技能 | 工具属性，提供底层能力 | 需要完成如翻译、格式转换、数据爬取等具体动作时 | **推荐**：明确任务步骤时使用。<br>**技巧**：可通过连接器串联多个技能完成复杂任务。 |
| 专家 | 角色属性，提供专业视角与经验 | 需要领域专家进行方案评审、代码审查或架构设计时 | **推荐**：遇到陌生领域或需要提升方案专业度时使用。<br>**技巧**：在提问时尽量提供详细背景，让专家更好地发挥作用。 |
| 灵感 | 成品属性，提供完整解决方案 | 接手全新任务，或者希望快速制作周报、竞品分析等标准化文档时 | **推荐**：毫无头绪或追求极致效率时首选。<br>**技巧**：先“做同款”，再根据实际情况微调 Prompt。 |

## 本章小结

本章详细介绍了 WorkBuddy 灵感模块的核心价值与操作方法。通过灵感模块，我们能够以极低的成本一键复刻优秀的场景解决方案，消除面对空白工作台的恐惧，享受社区智慧带来的效率红利。更重要的是，通过这一次“做同款”的完整体验，你已经在动手过程中接触到了技能、专家、连接器、模型等核心概念。在下一章中，我们将逐一拆解灵感背后的能力组件——从技能（Skill）到专家（Agent）与专家团（Team）。
