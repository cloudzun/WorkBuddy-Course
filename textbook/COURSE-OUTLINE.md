# WorkBuddy 效率进阶实训课程教材大纲

> **课程定位**：本课程面向**职场办公人士**，目标是让学员：① 理解 WorkBuddy 的产品定位、核心能力与功能体系；② 独立完成桌面端安装、配置与日常使用；③ 掌握任务创建、结果管理、助理接入、技能扩展、连接器配置等全链路操作；④ 能够在典型办公场景中高效运用 WorkBuddy 提升工作效率。
>
> **教材特点**：本教材基于培训实训课程深度重写，以官方文档（[WorkBuddy 文档站](https://www.workbuddy.cn/docs/workbuddy/Overview)）为权威依据，补充了官方文档中已发布但原课程未覆盖的功能。
>
> **版本基准**：以 WorkBuddy **当前最新版本**为准。产品界面与功能迭代较快，具体以实际产品为准。

---

## 第一部分：产品入门（第 1 章）

### 第 1 章 WorkBuddy 产品与基础入门
- **目标**：建立对 WorkBuddy 的全面认知，完成安装并熟悉主界面
- **要点**：
  - 产品定位：全场景 AI 办公工作台（官方定义与核心理念）
  - 四大核心能力：理解自然语言、自主规划执行、多模态任务处理、本地文件操作
  - 与传统 AI 对话的差异（行动力、文件操作、任务复杂度、输出形态）
  - 三大适用场景：日常办公、代码开发、设计创意
  - 典型用户画像：移动办公者、创意产出者、数据分析者、OPC 创业者
  - 桌面端安装：系统要求、Windows/Mac 安装指南、首次登录（微信扫码）
  - 主界面三区域：左侧导航、中间对话区、右侧结果区
  - 新建任务栏：工作模式、模型、技能、连接器、工作空间、权限等配置入口（以产品界面为准）
  - 任务六种状态：进行中、已完成、失败、待处理、规划中、已归档（[官方文档《任务管理》](https://www.workbuddy.cn/docs/workbuddy/Task-Management)）
  - 三种工作模式：Ask（问一问）/ Craft（做一做）/ Plan（想一想）
  - 专家中心、系统设置、模型配置、数据管理、记忆管理概览

## 第二部分：任务生命周期（第 2 章）

### 第 2 章 任务创建与结果管理
- **目标**：掌握从任务描述到产物交付的完整流程
- **要点**：
  - 任务描述黄金法则：明确目标与验收标准、提供上下文、指定输出格式、避免歧义
  - 官方推荐的“三要素公式”：做什么 + 有什么 + 怎么样
  - 上下文挂载方式（本地文件/文件夹授权、链接 URL、图片截图、知识库引用等）（[官方文档《创建任务》](https://www.workbuddy.cn/docs/workbuddy/Create-Task)）
  - 支持的文件类型完整列表（[官方文档《任务对话》](https://www.workbuddy.cn/docs/workbuddy/Conversation)）
  - 隐私授权边界与安全机制
  - 任务对话与追问技巧：上下文保持、修正方向、打断机制、分步确认
  - 追问 vs 新建任务的判断标准
  - 结果查看视图：产物、工作空间文件、变更、浏览器（概览）
  - 产物预览、下载与分享（支持上传到腾讯文档/ima/乐享/网盘）
  - 工作空间概念、按空间组织任务、任务归档与回溯
  - 多任务并行与切换

## 第三部分：能力体验与拆解（第 3-4 章）

### 第 3 章 灵感模块
- **目标**：通过一键复刻社区成品跑通完整流水线，消除“空白恐惧”，带出后续核心概念
- **要点**：
  - 灵感 = 社区精选成品集（Prompt + Skill + 专家配置）
  - 灵感为何“开箱即用”：AI 执行链路（可以理解为：用户输入 → 提示词组装 → 模型推理 → 结果整合）
  - 四大优势：场景覆盖、节省 Token、一键复刻、社区智慧
  - 操作流程：入口 → 选择 → 制作 → 查看产物
  - 灵感 vs 技能 vs 专家的定位差异速记（后续章节逐一拆解）

### 第 4 章 技能、专家与专家团（合并原技能与专家中心章节）
- **目标**：拆解灵感流水线背后的能力组件，理解“工具 → 方法 → 团队”的能力升维链
- **要点**：
  - 技能 = 给 AI 配备的工具函数（Function Calling 机制）
  - 技能与普通对话的区别（一致性、可重复性、能力边界）
  - 安全沙箱与权限控制
  - 技能市场：推荐区与已安装区；三种安装方式：上传导入、查找、创建（自我进化）
  - 日常操作：启用/关闭、搜索、卸载
  - 十大零成本技能精选（Agent Browser、办公文档四件套、Local Whisper 等）
  - 专家 = 独立人设 + 方法论 + 工具链（单 Agent）
  - 专家团 = 团长 + 多专家 + 协作流程（Multi-Agent）
  - Skill / 专家 / 专家团三者辨析（能力进阶链：工具 → 方法 → 团队）
  - Multi-Agent 协作原理（需求理解 → 任务拆解 → 智能分配 → 协同执行 → 整合交付）
  - 召唤流程：浏览 → 选角色 → 注意积分 → 描述任务；创建自定义专家/专家团
  - 专家中心多领域分类（覆盖数量以产品为准）、五类典型专家团、多团协作（产品-内容-落地）

## 第四部分：数据与引擎（第 5-6 章）

### 第 5 章 连接器与资料库（合并原连接器与资料库章节）
- **目标**：掌握外部数据接入的通用机制与文档知识闭环
- **要点**：
  - 连接器 = 基于 MCP 协议的外部服务桥梁；技能（本地能力） vs 连接器（远程接入）的关系
  - MCP 协议原理（Client-Server 模型、Tools/Resources/Prompts、stdio / Streamable HTTP 传输）
  - OAuth 2.0 授权流程
  - 腾讯生态连接器：QQ 邮箱、腾讯乐享、腾讯文档、腾讯会议、TAPD、腾讯网盘等（以产品/官方文档为准）
  - 第三方服务（GitHub、Notion 等）可通过自定义 MCP 连接器接入
  - 自定义 MCP 连接器配置（mcp.json 编辑）、腾讯云 MCP 市场
  - 解绑/重连/安全排查
  - 资料库 = AI × 文档深度集成；三大知识库平台：腾讯文档、ima 知识库、乐享知识库
  - 双模搜索：语义搜索 + 关键词搜索；任务引用文件（勾选/悬停两种方式）
  - 产物存回资料库（闭环：取 → 用 → 存）；解除绑定与安全最佳实践

### 第 6 章 模型配置（独立成章）
- **目标**：理解 WorkBuddy 的执行引擎，掌握模型选择、接入策略与成本管理
- **要点**：
  - 大模型推理模式：标准推理 vs 深度思考（Thinking / Chain-of-Thought）
  - 内置模型概览（Auto / Hunyuan / GLM / MiniMax / Kimi / DeepSeek）与能力标记机制
  - 模型选择策略（日常/多模态/复杂推理/Agent 场景）+ 选型口诀
  - 四种自定义模型接入方式：Token Plan / Coding Plan / 提供商接入 / Ollama 本地
  - 配置四要素（Base URL / 模型名称 / API Key / 能力标记）与连通验证
  - Ollama 本地部署实操步骤
  - 积分与成本管理：消耗三条规律（模式/实体/上下文）+ 成本优化实践
  - 模型管理最佳实践与 API Key 管控

## 第五部分：执行自主性（第 7-8 章）

### 第 7 章 助理连接配置
- **目标**：理解助理的工作原理，掌握各渠道接入方法（人不在电脑前）
- **要点**：
  - 助理核心定义：远程操控本机 WorkBuddy 的消息通道
  - 助理任务与普通任务的差异
  - 通信原理：WebSocket 长连接、平台通用 Token 签名与 EncodingAESKey 加密、运行四前提
  - 渠道接入（官方《助理》页归纳 6 个 IM 平台：微信助理、微信客服号、企业微信、QQ、飞书、钉钉；另有元宝派与微信小程序移动端入口）：
    - 微信助理（扫码型，零配置）
    - 微信小程序（扫码型，支持产物同步）
    - 微信客服号（扫码型）
    - 元宝派（凭据型，AppID + AppSecret）
    - QQ（凭据型，需实名认证）
    - 企业微信（长连接 / URL 回调两种模式）
    - 飞书接入（官方文档新增）
    - 钉钉机器人接入（官方文档新增）
  - 常见问题与四步排查法

### 第 8 章 自动化
- **目标**：理解自动化任务的适用场景，掌握创建与管理方法（人完全不在场）
- **要点**：
  - 自动化 = 周期性/重复性任务的定时执行
  - 定时规则：设置执行频率和生效日期区间（[官方文档《自动化》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)）；运行前提（同助理：开机+运行+联网）
  - 自动化 vs 手动任务的选择，混合模式过渡
  - 核心配置项（名称 / 工作空间 / 提示词 / 选择模型和技能 / 定时规则 / 推送到小程序，[官方文档《自动化》](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)）
  - 提示词最佳实践（在任务描述三要素基础上追加：明确格式、限定数量、给出示例、指定异常处理）
  - 任务模板（工作/学习/生活/娱乐四类）
  - 推送到 WorkBuddy 小程序
  - 安全与权限边界

## 第六部分：综合实战与商业应用（第 9 章）

### 第 9 章 典型办公场景综合实战与 OPC 一人公司
- **目标**：掌握四类高频办公场景的完整操作链路，理解 OPC 一人公司理念（收官章）
- **要点**：
  - 文档生成（工作报告、技术文档、会议纪要、模块化复用）
  - 数据分析与可视化（导入 → 分析 → 图表 → 结论）
  - PPT 与演示文稿生成（大纲 → 内容 → 美化 → 演讲稿）
  - 深度研究与咨询简报（目标 → 多源整合 → 自检 → 交付）
  - 案例串联：数据分析 → 报告 → PPT 三场景流水线
  - 人机双写（官方文档新增功能）
  - 设计创意模式（官方文档新增功能）
  - 轻量发布（官方文档新增功能）：本地 HTML 一键发布为 workbuddy.link 在线链接，可配合 CSV 搭建轻应用
  - 自驱四要素：说清目标、指定输出、限定边界、自检后交付
  - OPC 概念与背景（定义、人群、AI 执行层能力、发展前景）
  - 超级个体四大特征与三层能力模型（L1 单点放大 / L2 流程编排 / L3 系统自治）
